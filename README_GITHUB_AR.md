# بناء APK بدون Android Studio

يمكن بناء التطبيق على GitHub Actions من خلال خوادم GitHub، لذلك لا يحتاج جهازك إلى Android Studio أو Android SDK.

## الخطوات
1. أنشئ مستودعًا جديدًا على GitHub باسم `Medoo`.
2. ارفع كل ملفات هذا المشروع إلى المستودع، بما فيها المجلد `.github/workflows`.
3. من تبويب **Actions** اختر **Build Medoo APK**.
4. اضغط **Run workflow** إذا لم يبدأ البناء تلقائيًا.
5. انتظر انتهاء المهمة.
6. افتح نتيجة التشغيل، ثم من قسم **Artifacts** نزّل `Medoo-APK`.
7. فك الضغط عن الملف الناتج وستجد `app-debug.apk`.
8. انقل APK إلى هاتفك وثبته. إذا طلب Android السماح بالتثبيت من هذا المصدر، فعّل السماح لمدير الملفات/المتصفح الذي فتحت منه APK.

ملاحظة: هذا APK تجريبي (debug). لا تستخدمه لتوزيعه على متجر Google Play.
