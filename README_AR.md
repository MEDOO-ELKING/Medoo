# M̱͗e̲͎͋d̷͈̈o̠ͯ̓ọ̢̲ͣ

تطبيق Android تجريبي لحظر أرقام واتساب غير المحفوظة تلقائيًا.

## المتطلبات
- Android 10 أو أحدث.
- WhatsApp الرسمي.
- Android Studio حديث.
- Java 17 مفضلًا مع Android Gradle Plugin 8.6.1.

## كيف يعمل
1. Notification Listener يراقب إشعارات WhatsApp فقط.
2. يستخرج رقم الهاتف عندما يظهر الرقم داخل الإشعار.
3. يبحث في جهات الاتصال عبر ContactsContract.
4. إذا لم يكن الرقم محفوظًا، يفتح محادثة الرقم عبر wa.me.
5. Accessibility Service تحاول تنفيذ: المزيد → حظر → تأكيد.

## التثبيت
1. افتح هذا المجلد في Android Studio.
2. انتظر Gradle Sync.
3. وصّل الهاتف بــ USB مع USB debugging، أو استخدم محاكي Android.
4. اضغط Run.
5. من التطبيق:
   - اسمح بقراءة جهات الاتصال.
   - افتح وصول الإشعارات وفعل Medoo.
   - افتح إمكانية الوصول وفعل Medoo.
   - فعّل الحظر التلقائي.
6. أرسل رسالة اختبار من رقم غير محفوظ.

## ملاحظات مهمة
- التطبيق لا يرسل رسائل ولا يقرأ محتوى المحادثة لغرض المعالجة.
- واجهة WhatsApp ليست API رسمية للحظر، لذلك خطوات Accessibility قد تتغير من إصدار لآخر.
- إذا لم يظهر رقم الهاتف في إشعار WhatsApp فلن يخمن التطبيق هوية المرسل ولن يحظره.
- لا تستخدم Accessibility لهذا التطبيق إذا لم تكن موافقًا على الصلاحية؛ فهي صلاحية قوية لأنها تسمح للتطبيق بالتفاعل مع واجهة التطبيقات.
